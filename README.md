# Apple College of Nursing

Official web application for **Apple College of Nursing**, an institution under **Orange Colleges** sponsored by **Telangana Xpress Educational Society (Regd. 214/2025)** located in Bandlaguda, Keesara, Hyderabad, Telangana.

## Features
- Modern, accessible, responsive institutional website built with React 19, TypeScript, Vite, Tailwind CSS, and Framer Motion.
- Program details for **B.Sc. Nursing (4-Year Degree)** and **General Nursing & Midwifery (GNM 3-Year Diploma)**.
- Campus infrastructure, simulation labs, library, hospital postings, and admissions portal.
- Mobile-friendly navigation, admission announcement ticker, interactive enquiry modal, and direct WhatsApp support integration.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Routing:** React Router v7
- **Styling:** Tailwind CSS v4 + Lucide React Icons
- **Animation:** Framer Motion + GSAP
- **Deployment:** Static SPA (Vite build)

## Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
